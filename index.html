🗑️ Akıllı Çöp Kovası Projesi: Ağırlık Sensörü Dönüşümü

Bu projede, çöp kovasının doluluk oranını mesafe yerine kilogram (ağırlık) bazlı ölçmek amacıyla ultrasonik sensör yerine bir Yük Hücresi (Load Cell) ve HX711 Amplifikatör modülü kullanılmıştır. HX711, çöp kutusunun altındaki küçük analog ağırlık değişimlerini Raspberry Pi 5'inizin okuyabileceği dijital sayılara dönüştürür.

🛠️ Donanım Kurulumu

Yük hücresi düzeneğini çöp kovanızın tabanına yerleştirin. HX711 modülünün Raspberry Pi 5 bağlantılarını aşağıdaki şemaya göre yapın:

  • VCC → Pi Pin 2 veya 4 (5V Güç)
  • GND → Pi Pin 6 (Toprak / Ground)
  • DT (Data) → Pi GPIO 5 (Pin 29)
  • SCK (Clock) → Pi GPIO 6 (Pin 31)

🔑 Bildirim Anahtarlarını (VAPID) Üretme

Web tarayıcınıza anlık bildirim gönderebilmek için güvenlik anahtarlarına ihtiyacınız vardır. Raspberry Pi terminalinde aşağıdaki tek satırlık Python komutunu çalıştırarak size özel benzersiz Public ve Private anahtarlarınızı anında oluşturun:

python3 -c "from pywebpush import webpush_vapid_keys; keys = webpush_vapid_keys(); print(f'\nPUBLIC KEY:\n{keys[\"public_key\"]}\n\nPRIVATE KEY:\n{keys[\"private_key\"]}\n')"

Terminal ekranına basılan bu anahtarları kopyalayın ve aşağıdaki Python kodundaki ilgili yerlere yapıştırın.

📝 Güncellenmiş Python Kodu (app.py)

Aşağıdaki betik, arka planda çöpün ağırlığını sürekli izler. BIN_EMPTY_WEIGHT değeri sayesinde boş kovanın kendi ağırlığı dara olarak düşülür. Ağırlık belirlenen sınırı geçtiğinde web bildirimi tetiklenir.

# app.py
from flask import Flask, render_template, request, jsonify
from hx711 import HX711 
from pywebpush import webpush, WebPushException
import threading
import time
import json

app = Flask(__name__)

# ================================================================
# KİLOGRAM AYARLARINI BURADAN ELİNİZLE DEĞİŞTİREBİLİRSİNİZ:
# ================================================================
BIN_EMPTY_WEIGHT = 0.65   # Kendi boş çöp kovanızın ağırlığı (Kilogram olarak)
MAX_KG_THRESHOLD = 4.50   # Çöpün ulaşmasını istediğiniz maksimum ağırlık (Kilogram olarak)
# ================================================================

REFERENCE_UNIT = 420.0    # Kalibrasyon faktörü (Sensörünüze özel hesaplanmalıdır)

# Terminalden ürettiğiniz VAPID Anahtarlarını buraya yapıştırın:
VAPID_PUBLIC_KEY = "ÜRETTİĞİNİZ_PUBLIC_KEY_BURAYA"
VAPID_PRIVATE_KEY = "ÜRETTİĞİNİZ_PRIVATE_KEY_BURAYA"
VAPID_CLAIMS = {"sub": "mailto:eposta-adresiniz@example.com"}

hx = HX711(dout_pin=5, pd_sck_pin=6)
hx.set_scale_ratio(REFERENCE_UNIT)
hx.reset()
hx.tare() 

subscriptions = []
notified = False

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/subscribe', methods=['POST'])
def subscribe():
    subscription_data = request.get_json()
    if subscription_data not in subscriptions:
        subscriptions.append(subscription_data)
    return jsonify({"status": "success"})

def send_push_notifications(net_cop_kilosu):
    global notified
    payload = json.dumps({
        "title": "Çöp Kovası Doldu! 🗑️",
        "body": f"İçindeki çöp miktarı {net_cop_kilosu:.2f} kg sınırına ulaştı. Lütfen boşaltın!"
    })
    
    for sub in subscriptions[:]:
        try:
            webpush(
                subscription_info=sub,
                data=payload,
                vapid_private_key=VAPID_PRIVATE_KEY,
                vapid_claims=VAPID_CLAIMS
            )
        except WebPushException as ex:
            if ex.response and ex.response.status_code in:
                subscriptions.remove(sub)

def monitor_weight():
    global notified
    while True:
        try:
            raw_weight = hx.get_weight_mean(readings=5)
            toplam_kilo = raw_weight / 1000.0
            net_cop_kilosu = toplam_kilo - BIN_EMPTY_WEIGHT
            
            if net_cop_kilosu < 0: 
                net_cop_kilosu = 0.0 
                
            print(f"Güncel Çöp: {net_cop_kilosu:.2f} kg / Sınır: {MAX_KG_THRESHOLD} kg")
            
            if net_cop_kilosu >= MAX_KG_THRESHOLD and not notified:
                send_push_notifications(net_cop_kilosu)
                notified = True
            elif net_cop_kilosu < (MAX_KG_THRESHOLD - 0.2): 
                notified = False
                
        except Exception as e:
            print(f"Ağırlık Sensörü Hatası: {e}")
            
        time.sleep(4)

if __name__ == '__main__':
    threading.Thread(target=monitor_weight, daemon=True).start()
    app.run(host='0.0.0.0', port=5000)

🌐 Projeyi İnternete Açma (playit.gg Kurulumu)

Oluşturduğunuz web sitesine ev dışındayken de telefonunuzdan erişebilmek için port yönlendirme yapmak yerine playit.gg tünelleme yazılımını kullanacağız:

  1. Raspberry Pi terminalinde playit.gg istemcisini kurun: 
    curl -SsL https://github.io | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/playit.gpg > /dev/null
echo "deb [signed-by=/etc/apt/trusted.gpg.d/playit.gpg] https://github.io ./ " | sudo tee /etc/apt/sources.list.p/playit.list
sudo apt update && sudo apt install playit -y
  2. Kurulum bittikten sonra terminale sadece playit yazarak başlatın. Ekranda size verilen özel **Claim Linkini** tarayıcınızda açıp bir hesap oluşturun.
  3. playit.gg paneli üzerinden Add Tunnel butonuna tıklayın:
    • Tunnel Type: HTTP
    • Local Port: 5000
  4. Sistem size *.playit.gg uzantılı kalıcı ve ücretsiz bir internet adresi verecektir. Artık sitenize bu adresten tüm dünya erişebilir!
